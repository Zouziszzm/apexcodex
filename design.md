# Design Language & UI System Specification: `apexcodex` ("Magus")

This document serves as the absolute blueprint for recreating the high-fidelity, sensory, and chronodynamic UI language of **apexcodex**. It details the styling principles, grid structure, animations, customized components, color/typography systems, and user interaction model.

---

## 1. UI Philosophy & Aesthetic Identity

The design language of `apexcodex` can be described as **Chronodynamic Organic Minimalism with Tactile Feedback**. It is stark, structured, and typography-first, but paired with playful, sensory, and highly interactive motion.

### Core Pillars
1. **Adaptive Chronodynamism (Seasonal & Hourly Theme)**: The UI is not static. It adapts to the physical calendar season and time of day, offering 56 uniquely curated, low-contrast, muted color palettes. 
2. **Minimalism with Warmth**: Standard borders and elements are razor-sharp (straight edges, low border-radius, clean lines), but the addition of hand-drawn sketched markings (`rough-notation`) introduces human warmth and organic texture.
3. **Physical & Tactile Feedback**: Digital interactions should mimic physical hardware. Clicks trigger white-noise "ticks" generated by low-latency audio synthesis, and visual clicks emit canvas-rendered sparks.
4. **Cinematic Motion (Staggered Stretches & Reveals)**: Page entrances are staggered, and key details (like lines under titles and divider marks) sweep outward from the center, creating a sense of physical mechanical assembly on-screen.
5. **Interactive 3D Centerpiece**: High-precision layouts are juxtaposed with a rotating, low-fidelity 3D pixelated spirit (voxel art), creating a bridge between vintage computing and modern web design.

## 2. Technical Stack Specifications

To recreate this UI perfectly, the following engineering framework should be followed:
- **Core Environment**: React 19 + Next.js (App Router) + TypeScript.
- **Styling**: Tailwind CSS v4 utilizing modern `@theme` syntax and standard fluid CSS layout rules.
- **Animation Suite**: GSAP (GreenSock Animation Platform) + `@gsap/react` for complex stagger grids, line sweeps, and intersection animations.
- **3D Graphics**: Three.js (WebGL) + `OrbitControls` for responsive, interactive voxel rendering.
- **Low-Latency Audio**: Web Audio API (Tone.js) for physical interaction audio synthesis.
- **Generative Sketches**: `rough-notation` for canvas-drawn sketchy highlighting, underlines, and circles.

## 4. Chronodynamic Color System

The primary style driver is a dynamic color matrix based on the user's local season and time of day. 
- **Transitions**: The base element `:root` transitions color parameters smoothly over **0.8s** to make theme changes feel like natural lighting shifts:
  ```css
  transition: background-color 0.8s ease, color 0.8s ease, border-color 0.8s ease;
  ```

### Curated Color Variable Keys
Every theme applies custom values to these CSS variable tokens:
- `--bg`: Viewport base background (highly soft, low-luminance light or high-depth dark).
- `--surface`: Containers and background fills for active segments.
- `--border`: Fine lines and interactive division lines.
- `--title`: Core navigation items, headers, and focus text.
- `--display`: Hero title text.
- `--body`: General paragraph and description copy.
- `--subtext`: Secondary captions, metadata, and timestamps.
- `--accent`: Focus elements, highlights, and hovers.

### Time & Season Logic Matrix
Seasons are computed from the calendar month:
- **Spring**: March (2) - May (4)
- **Summer**: June (5) - August (7)
- **Autumn**: September (8) - November (10)
- **Winter**: December (11) - February (1)

Times of day are computed from local 24-hour clocks:
- `night-00`: `00:00 - 04:59`
- `dawn`: `05:00 - 06:59`
- `morning`: `07:00 - 10:59`
- `noon`: `11:00 - 13:59`
- `afternoon`: `14:00 - 16:59`
- `dusk`: `17:00 - 18:59`
- `evening`: `19:00 - 23:59`

## 5. Typography System

The typography is highly structured, modern, and readable, leveraging a single core sans-serif font family.

- **Primary Font**: `Hanken Grotesk` (Google Font), falling back to standard clean system fonts.
  ```css
  font-family: "Hanken Grotesk", ui-sans-serif, system-ui, sans-serif;
  ```
- **Fluid Font Sizing**: Uses viewport-relative math via `clamp` to maintain absolute structural layout without breakpoint snapping:
  - `--font-size-display`: `clamp(2.67rem, calc(2.67rem + 1.145rem * ((100vw - 20rem) / 220rem)), 3.815rem)`
  - `--font-size-heading`: `clamp(2.136rem, calc(2.136rem + 0.916rem * ((100vw - 20rem) / 220rem)), 3.052rem)`
  - `--font-size-title`: `clamp(1.709rem, calc(1.709rem + 0.732rem * ((100vw - 20rem) / 220rem)), 2.441rem)`
  - `--font-size-subtitle`: `clamp(1.368rem, calc(1.368rem + 0.585rem * ((100vw - 20rem) / 220rem)), 1.953rem)`
  - `--font-size-kicker`: `clamp(1.094rem, calc(1.094rem + 0.469rem * ((100vw - 20rem) / 220rem)), 1.563rem)`
  - `--font-size-body`: `clamp(0.875rem, calc(0.875rem + 0.25rem * ((100vw - 20rem) / 220rem)), 1.125rem)`
  - `--font-size-body-sm`: `clamp(0.7rem, calc(0.7rem + 0.275rem * ((100vw - 20rem) / 220rem)), 0.875rem)`
  - `--font-size-caption`: `clamp(0.625rem, calc(0.625rem + 0.3928rem * ((100vw - 20rem) / 220rem)), 0.875rem)`
- **Kerning (Letter Spacing)**: Extended displays are slightly tight to look premium, while body sizes are natural:
  - Display: `-0.02em`
  - Heading: `-0.015em`
  - Title: `-0.01em`
- **Line Heights**:
  - Heading: `1.15`
  - Body: `1.6`
  - Tight Layouts: `1.5`

## 6. Micro-Interactions & Tactile Synthesis

To bridge the screen gap and provide a high-end tactile feel, three distinct systems run simultaneously on mouse click and hover:

### A. Programmatic Sound Synthesis (Low Latency)
Every key layout interaction (theme toggle, accordion, navigation routing, tab clicks) synthesizes a subtle hardware-like click sound.
- **Engine**: Tone.js is imported dynamically. It triggers a short `NoiseSynth` white noise burst to sound like a natural, physical mechanical button:
  ```typescript
  // Synthesis Settings
  const synth = new Tone.NoiseSynth({
    noise: { type: "white" },
    envelope: { attack: 0.001, decay: 0.02, sustain: 0 }
  }).toDestination();
  synth.volume.value = -35; // kept extremely quiet and subtle
  
  // Triggers
  synth.triggerAttackRelease("32n");
  ```

### B. Interactive Canvas Spark Effect (`ClickSpark`)
A global overlay canvas catches click coordinates and emits a radial spark explosion.
- **Visuals**: Emits 7-10 round-capped lines radially at uniform geometric angles. Lines quickly expand outwards and fade in length over **300ms - 400ms** using an `ease-out` progression, using `var(--title)` as the active color to match seasonal states.

### C. GSAP Stretches & Hover Pulses
Sections feature horizontal separator lines that start at width scale zero (`scaleX(0)`) and slide outwards on page entry.
- **Hover Sweep**: When hovering row items (e.g. experience companies or projects), a linear-gradient pulse slides across the separator line from left to right:
  ```typescript
  gsap.fromTo(pulse, 
    { x: "-100%", opacity: 0 }, 
    { x: "100%", opacity: 1, duration: 1, repeat: -1, ease: "power2.inOut" }
  );
  ```

## 7. Interactive Custom Components Specification

Recreating this UI requires implementing these key proprietary visual components:

### 1. `DiaTextReveal` (Diagonal Text Reveal)
A visual typography animation where text starts transparent and is revealed via a gradient sweep.
- **Mechanism**: Utilizes `background-clip: text` and Webkit prefixes. A dynamic `linear-gradient` is animated in position using GSAP. As the sweep passes over the characters, they transition from transparent/accented colors to the solid `textColor`.
- **Cycler Mode**: Supports passing an array of strings. The component automatically measures their bounding widths using a hidden absolute ghost element, cycles text on a timer, and smoothly animates the container width to fit the incoming text length via GSAP without layout shifts.

### 2. `AnimatedThemeToggler` (Geometric ClipPath Transition)
Theme toggles do not simply flip. They sweep the new color styling across the viewport using HTML5 View Transitions paired with custom geometric clipPaths.
- **Shapes Supported**: `circle`, `square`, `triangle`, `diamond`, `hexagon`, `rectangle`, `star`.
- **Logic**: Evaluates the toggler coordinates or screen center, calculates the bounding radius to completely cover the screen (`Math.hypot`), and triggers the Web Animation:
  ```typescript
  document.startViewTransition(() => {
    // apply dark class to HTML document
  }).ready.then(() => {
    document.documentElement.animate(
      { clipPath: [clipStart, clipEnd] },
      { duration: 400, easing: "ease-in-out", fill: "forwards", pseudoElement: "::view-transition-new(root)" }
    );
  });
  ```

### 3. `Highlighter` (Organic Hand-Drawn Markings)
Draws skeletal underlines, boxes, circles, or strikes on elements.
- **Mechanism**: Wrapped using `rough-notation`. On intersection or mount, it runs a canvas-drawing process to paint hand-drawn sketchy underlines (`action="underline"`) under focus text (e.g., React, TypeScript, Rust) with a slight execution delay to let page entrance finishes first.
- **Responsiveness**: Re-draws the sketchy canvas markup automatically whenever a `ResizeObserver` detects container dimensions have adjusted.

### 4. `AnimatedGradientText` (Dynamic Hover Text)
Text that has standard styling until hovered, where it transforms into a moving gradient.
- **Mechanism**: Features Tailwind hover rules that apply a repeating horizontal gradient shifting back and forth via an infinite `@keyframes` shift:
  ```css
  @keyframes gradient {
    to { background-position: 300% 0; }
  }
  ```

### 5. `TransitionProvider` (Global Route Transition Overlay)
Prevents standard instant routing.
- **Mechanism**: Page transitions trigger a full-screen exit animation where an overlay with background color matching the chronodynamic color state (`var(--bg)`) fades in over `0.8s`. Once solid, the router changes pages, and an entrance animation fades out the overlay.

### 6. `VoxelDog` (3D Spirit Showcase)
Renders a 3D pixelated creature model (`elvendeer.glb`).
- **Setup**: WebGLRenderer set with `alpha: true` and `antialias: true`. Renders using an `OrthographicCamera` matching container aspects, with an `AmbientLight` intensity of `Math.PI` (0xcccccc).
- **Controls**: Integrates `OrbitControls` that slowly auto-rotates the model. Users can click and drag to orbit or manipulate the 3D model, and an overlay controls button allows pausing/playing the rotation. GSAP fades the model canvas into view once GLTFLoader completes loading.

### 7. `DevToolbar` (Chronodynamic Simulator & Monitor)
A diagnostic drawer to monitor performance and debug the dynamic seasonal states.
- **Metrics**: Real-time FPS monitor calculated via `requestAnimationFrame` differentials, alongside page-load latency calculations using `window.performance.timing`.
- **Controls**: Grid options to override and force the site's active Seasonal attribute (`spring`, `summer`, `autumn`, `winter`) or Hourly attribute (`night-00`, `dawn`, `morning`, `noon`, `afternoon`, `dusk`, `evening`) in real-time, allowing developers to inspect color shifts.
